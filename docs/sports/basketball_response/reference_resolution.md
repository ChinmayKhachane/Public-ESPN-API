## Notes

- Resolution is intentionally shallow and representative. It follows only top-level sparse `$ref` responses and top-level `items[0].$ref` collections; it does not recursively expand every nested ESPN graph reference.
- Rows with `400`, `404`, `500`, or empty payloads stop at the initial endpoint because there is no final data URL to resolve.
- For SDK work, collection rows are the important ones: the collection URL gives pagination, while the final `items[0].$ref` URL shows the resource schema for individual items.
