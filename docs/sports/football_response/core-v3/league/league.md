# League

## https://sports.core.api.espn.com/v3/sports/football/{league}

Notes:
- Verified with `league=nfl` on 2026-05-07.
- Returns a compact league object.

## Example Response

```json
{
  "id": "28",
  "name": "National Football League",
  "displayName": "NFL",
  "abbreviation": "NFL",
  "slug": "nfl"
}
```
