# Season

## https://sports.core.api.espn.com/v3/sports/football/{league}/seasons/{season}

Notes:
- Verified with `league=nfl`, `season=2025` on 2026-05-07.
- The base season response is intentionally small.

## Example Response

```json
{
  "year": 2025,
  "startDate": "2025-07-31T07:00Z",
  "endDate": "2026-08-06T06:59Z"
}
```
